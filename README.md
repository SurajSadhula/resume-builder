# 📝 AI-Powered Resume Builder

## 🚀 Project Overview
AI-Powered Resume Builder is a modern web application designed to streamline resume creation with **dynamic skill selection**, **real-time previews**, and **structured form-based inputs**. Our goal is to integrate **AI-powered suggestions** to enhance resume content, ensuring **clarity, professionalism, and impact**.

## 📌 Current Features
✅ **User-Friendly Resume Form** – Clean UI with structured sections.  
✅ **Dynamic Skill Selection** – JSON-based skill management with `react-select`.  
✅ **PDF Export** – Generates a **selectable-text** resume using jsPDF.  
✅ **Modular Design** – Built using React components for scalability.  

## 🛠️ Technologies Used
- **Frontend:** React, React-Hook-Form, React-Select  
- **State Management:** Controlled React states  
- **PDF Handling:** jsPDF  
- **Styling:** CSS Modules  

## 🔄 Upcoming Features
🚀 **AI-Powered Resume Suggestions** – Auto-generate key points for Work Experience & Summary.  
🚀 **AWS Deployment** – Deploying to free-tier AWS for public access.  
🚀 **Optimized Resume Formatting** – Fine-tuned styles for professional export.

This project aims to bridge technology and career development, helping users create impactful resumes with AI-driven insights. Stay tuned for the AI-powered enhancements coming soon!
